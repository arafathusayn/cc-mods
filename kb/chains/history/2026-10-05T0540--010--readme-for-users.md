a heading that links to the mod's README. `2e2549d` moved the repository layout and the develop
and release steps to `CONTRIBUTING.md`. `f8d0cfa` led the README with what mods give a user.
ADR-0013 supersedes ADR-0012.

  one line for `/reload-plugins`, `update` and `uninstall`.

  catalog; unit tests cover the rendered section, an empty catalog and a missing description.
